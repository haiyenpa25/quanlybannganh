# DESIGN.md - Minimalist Native Mobile Design System

Official DESIGN.md specification for **ManagerTeams** adhering 100% to the user's reference screenshots.

## Palette Rationale

- **Surface Base (`#141c2e`)**: Deep midnight navy background, eliminating visual clutter.
- **Primary Accent (`#e58c67`)**: Warm Terracotta / Salmon Peach for floating action buttons, active tab indicators, and primary call-to-action buttons.
- **Tag Label (`#d48866`)**: Small uppercase orange-brown text for screen section tags (`MỖI CHÚA NHẬT · 19:30`, `6 BAN VIÊN`, `ĐỒNG HÀNH TRONG YÊU THƯƠNG`).
- **Selector Pills (`.pill-chip`)**: Interactive round option pills that turn terracotta `#e58c67` when selected.
